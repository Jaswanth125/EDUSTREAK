# 📚 How to Add Student Details - Complete Guide

## 🎯 Where to Add Students

You can add student details in **TWO ways**:

---

## ✅ Method 1: Admin Dashboard (Recommended)

### Step-by-Step Instructions:

1. **Login as Admin**:
   - Email: `admin@edustreak.com`
   - Password: `admin123`

2. **Go to Users Tab**:
   - Click on **"Users"** tab (2nd icon in bottom navigation)
   - You'll see "User Management" screen

3. **Click the "+" Icon** (top right corner)

4. **Fill in Student Details**:
   - **Full Name**: Enter student's full name (e.g., "John Doe")
   - **Email**: Enter student's email (e.g., "john@example.com")
   - **Password**: Enter password (minimum 6 characters)
   - **Role**: Select **"Student"** from dropdown
   - **Class**: Select which class the student belongs to
     - If no classes exist, go to **Classes Tab** first and create a class

5. **Click "Create User"** button

6. **Success!** Student is now added and can login.

---

## ✅ Method 2: Initialize Sample Data (Quick Start)

If you want to add multiple students quickly:

1. **Login as Admin**: `admin@edustreak.com` / `admin123`

2. **Click Refresh Icon** (top right) → **"Initialize Sample Data"**

3. **Click "Initialize"** button

4. **This creates**:
   - 9 example students
   - 2 classes (10A and 10B)
   - Teachers, parents, tasks, attendance, messages
   - All automatically assigned!

---

## 📋 Before Adding Students

### 1. Create Classes First (if needed):

1. Login as Admin
2. Go to **Classes Tab** (3rd icon)
3. Click **"+"** icon (top right)
4. Enter class name (e.g., "Class 10A")
5. Click **"Add"**

### 2. Then Add Students:

Follow **Method 1** above to add students to the classes.

---

## 🔍 What Happens After Adding?

Once a student is added:

✅ **Student can login** with their email and password  
✅ **Teacher can see them** in Students Tab  
✅ **Teacher can mark attendance** for them  
✅ **Teacher can assign homework** to them  
✅ **Student appears in class** automatically  

---

## 💡 Tips

1. **Email must be unique**: Each student needs a unique email address
2. **Password**: Keep it simple (students can change later if needed)
3. **Class assignment**: Students must be assigned to a class
4. **Batch add**: Use "Initialize Sample Data" to add multiple students at once

## 🆘 Troubleshooting

**Problem**: "No classes available"
- **Solution**: Go to Classes Tab and create a class first

**Problem**: "Email already exists"
- **Solution**: Use a different email address

**Problem**: "Password too short"
- **Solution**: Password must be at least 6 characters

---

## 📞 Need Help?

If you encounter any issues:
1. Make sure you're logged in as **Admin**
2. Check that classes exist (create them if needed)
3. Verify email is unique and valid
4. Ensure password is at least 6 characters
