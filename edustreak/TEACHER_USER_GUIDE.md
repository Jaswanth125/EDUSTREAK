## 1. 📊 Viewing Students

### How to Access:
1. Login as Teacher: `teacher1@edustreak.com` / `teacher123`
2. Go to **Students Tab** (bottom navigation - 4th icon)

### What You Can See:
- ✅ **All students** in your assigned classes
- ✅ **Student stats**: Streak, XP, Level
- ✅ **Attendance history** (last 30 days)
- ✅ **Attendance chart** (last 7 days)
- ✅ **Attendance percentage**

### Steps:
1. **Select Class**: Use dropdown at top to choose a class
2. **View Students**: Scroll through the list
3. **Expand Student Card**: Tap on any student card to see:
   - Attendance statistics
   - Attendance chart (last 7 days)
   - Present/Absent breakdown

### Features:
- **Real-time updates**: Student stats update automatically
- **Class filtering**: Switch between your assigned classes
- **Visual charts**: See attendance trends at a glance

## 2. ✅ Marking Attendance

### How to Access:
1. Login as Teacher
2. Go to **Attendance Tab** (bottom navigation - 1st icon)

### What You Can Do:
- ✅ **Mark students as Present/Absent**
- ✅ **View attendance by date**
- ✅ **Select different dates** (past 30 days)
- ✅ **Select different classes**

### Steps:
1. **Select Class**: Choose class from dropdown (top left)
2. **Select Date**: Click calendar button to choose date
3. **Mark Attendance**: 
   - ✅ **Green checkmark** = Mark as Present
   - ❌ **Red X** = Mark as Absent
4. **Auto-updates**: Streaks and XP update automatically when marking present

### Features:
- **Quick marking**: One tap to mark attendance
- **Visual feedback**: Green = Present, Red = Absent
- **Date selection**: Mark attendance for any past date
- **Auto gamification**: Present students get XP and streak updates

## 3. 📝 Assigning Homework

### How to Access:
1. Login as Teacher
2. Go to **Assign Tab** (bottom navigation - 2nd icon)

### What You Can Do:
- ✅ **Create new homework assignments**
- ✅ **Assign to entire class or specific students**
- ✅ **Set due dates**
- ✅ **Set XP rewards**
- ✅ **Set max marks**
- ✅ **View all your assignments**
- ✅ **Delete assignments**

### Steps to Assign Homework:

1. **Click the "+" icon** (top right) or **"Assign New Task"** button

2. **Fill in the form**:
   - **Task Title**: e.g., "Math Homework - Chapter 5"
   - **Description**: Detailed instructions
   - **Class**: Select which class (dropdown)
   - **Due Date**: Tap calendar icon to select date
   - **XP Reward**: Enter points (e.g., 50, 75, 100)
   - **Max Marks**: Enter maximum marks (e.g., 100)

3. **Click "Assign"** button

4. **Assignment Created**: 
   - All students in the class will see it
   - They can submit proof via file upload or messaging
   - You'll see it in the "Grade" tab when students submit

### Features:
- **Auto-assignment**: Assigns to all students in selected class
- **Due date tracking**: Shows overdue assignments
- **XP rewards**: Students earn XP upon completion
- **Real-time updates**: Students see assignments immediately

### Viewing Your Assignments:
- Scroll through the list to see all assignments
- See: Title, description, due date, student count, XP reward
- **Delete**: Click trash icon to delete an assignment

## 4. 🎓 Grading Assignments

### How to Access:
1. Login as Teacher
2. Go to **Grade Tab** (bottom navigation - 3rd icon)

### What You Can See:
- ✅ **All your assignments**
- ✅ **Submission status** (Pending/Submitted/Graded)
- ✅ **Progress bar**: Shows how many students submitted/graded
- ✅ **Due dates and max marks**

### Steps to Grade:

1. **Click on any assignment** to open grading screen

2. **View Student Submissions**:
   - See all students assigned to the task
   - **Status indicators**: 
     - 🟠 **Pending**: Not submitted yet
     - 🔵 **Submitted**: Waiting for grading
     - 🟢 **Graded**: Already graded

3. **For Submitted Assignments**:
   - **View proof**: See uploaded images/files
   - **Enter marks**: Type marks (0 to max marks)
   - **Enter feedback**: Write feedback for student
   - **Click "Submit Grade"** button

4. **Grading Updates**:
   - Student sees grade immediately
   - XP is awarded based on marks
   - Badges may be awarded automatically

### Features:
- **Visual proof viewing**: See student's submitted work
- **Marks validation**: Ensures marks are within range
- **Feedback system**: Provide written feedback
- **Progress tracking**: See how many students submitted/graded
- **Real-time updates**: Grades appear instantly to students

## 6. 💬 Messaging Students/Parents

### How to Access:
1. Login as Teacher
2. Go to **Messages Tab** (bottom navigation - 5th icon)

### What You Can Do:
- ✅ **View all conversations** with students and parents
- ✅ **Start new conversations**
- ✅ **Send messages** with text
- ✅ **Send files** (images, documents)
- ✅ **Link messages to tasks** (for proof submission)

### Steps:

1. **View Conversations**:
   - See list of all chats
   - See last message preview
   - See timestamp

2. **Start Chat**:
   - Click on any conversation
   - Or contact student/parent from Students tab

3. **Send Messages**:
   - Type message in text field
   - Click send icon
   - Or attach file (📎 icon) then send

4. **File Attachments**:
   - Click attachment icon
   - Select image or file
   - File uploads automatically
   - Message includes file

### Features:
- **Real-time messaging**: Messages appear instantly
- **File sharing**: Send images, PDFs, documents
- **Task linking**: Messages can link to assignments
- **Chat history**: All conversations saved

## 7. 👥 Adding Students (Admin Function)

### ⚠️ Important Note:
**Teachers cannot add students directly**. Only **Admin** users can add students.

### How Admin Adds Students:

1. **Login as Admin**: `admin@edustreak.com` / `admin123`
2. **Go to Admin Dashboard** → **Users Tab**
3. **Click "Add User"** button
4. **Fill in student details**:
   - Name
   - Email
   - Password
   - Role: Select "Student"
   - Class: Select which class
5. **Click "Create User"**

### Alternative: Use Seed Data
- Admin can click **"Initialize Sample Data"** button
- This creates 9 example students automatically
- Students are assigned to classes automatically

### After Students Are Added:
- Teachers will see them in **Students Tab**
- Teachers can mark their attendance
- Teachers can assign them homework
- Teachers can grade their assignments

## 💡 Tips & Best Practices

1. **Mark Attendance Daily**: 
   - Use Attendance tab every day
   - Students earn XP and maintain streaks

2. **Assign Homework Regularly**:
   - Set clear due dates
   - Provide detailed descriptions
   - Use appropriate XP rewards

3. **Grade Promptly**:
   - Check Grade tab regularly
   - Grade submissions within a few days
   - Provide constructive feedback

4. **Communicate Often**:
   - Use Messages tab to stay in touch
   - Respond to student questions
   - Share updates with parents

5. **Monitor Student Progress**:
   - Check Students tab regularly
   - View attendance trends
   - Identify students who need support

If you encounter any issues:

2. Verify you have classes assigned
3. Make sure students exist in your classes
4. Check Firebase rules are deployed (if permission errors)
